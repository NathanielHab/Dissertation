This code was used to generate tables and figures for Nathaniel Haboucha's 2026 Master's dissertation for UCL.

In order to run this code, the user must access National Travel Survey data files (Tab format) from ONS or the NTS itself.

Instructions on how to use this code are included in the MasterScript.py file.

Elements of this code can be used to create parquet files from NTS Tab files, as well as to merge multiple files together (eg. combining individual survey data with trip survey data).

Most of the analysis that can be performed with this code involves comparing data from one period to another. In the case of the dissertation these periods were pre-COVID (2015-19) and post-COVID (2023-24).
The goal of sharing this repository is to make NTS data more easily analysed when it is updated annualy. 

Further instructions are included in the MasterScript.py
